# Demo video script (3–4 minutes)

Talk to the camera; click as you speak. Dark UI should be on screen the whole time.

**0:00–0:25 Problem**  
“Platforms dump thousands of courses on you. The real question is *what should I do next week, in what order, given my hours?* That’s what LearnPath AI answers.”

**0:25–0:50 Home**  
Click **Use Data Scientist**. “Cold start in one click: career skill map, 10 hours a week, 24-week goal.”

**0:50–1:50 Learning Path**  
Show metrics: items, calendar weeks, study hours, coverage. Expand first course: why-text + score bars. Scroll to a project. “Hybrid ranker — TF-IDF, career skills, gaps — then NetworkX orders prerequisites.” Download Markdown.

**1:50–2:30 Compare**  
Compute three paths. “Fast-track if I’m busy, deep if I have time. Same goal, different life.” Click **Use fast-track**.

**2:30–3:10 Dashboard**  
Skill radar. Mark first item completed. “Skills unlock and the remaining path is rebuilt — not a static PDF.”

**3:10–3:40 Chat (optional)**  
Paste: “I can only study 6 hours per week.” Save slider + mention regenerate. “Constraints change the calendar, not just the chatbot reply.”

**3:40–4:00 Close**  
“Works without OpenAI. The intelligence is the hybrid engine and the graph. That’s the product.”
